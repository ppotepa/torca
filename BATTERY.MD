# Runtime power architecture

The previous "Attention-Driven Runtime v2" working record has been retired.
It described transitional mechanisms such as periodic background rendezvous
cadence and dual policy/scheduler ownership that are no longer the direction
of the codebase.

The canonical active plan and acceptance invariants are in
[`docs/plans/BATTERY1.md`](docs/plans/BATTERY1.md). The durable architecture is
documented in [`docs/architecture/runtime-control.md`](docs/architecture/runtime-control.md),
and device validation lives in
[`docs/validation/runtime-power.md`](docs/validation/runtime-power.md).

Historical details remain available through Git history.
