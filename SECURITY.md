# Security policy

Torca 0.1 is an experimental source baseline and must not be represented as audited or production-safe.

Do not report sensitive vulnerabilities in public issues. Contact the repository owner privately with the affected version, reproduction steps, impact and any proposed mitigation. Do not include real private keys, pairing capabilities, message plaintext or database keys.

Security-sensitive changes require focused tests, threat-model updates and explicit review of logs, bridge DTOs, persistence and wire compatibility.
