## Completed evidence

- `02-00` through `02-13`: baseline, Bridge/runtime cleanup, daily-use UI, attachments, pairing recovery, diagnostics, verification, settings/localization and split CI gates.
- `02-14`: Read state is viewport/lifecycle aware and remote read receipts are an independent privacy preference.
- `02-15`: local encrypted state no longer waits for Tor during `NativeEngineRuntime` construction. Network host composition runs on a background startup worker with `starting/degraded` hints and retry; RuntimeHost mutation waits are bounded and slow accepted commands may complete after the caller returns; snapshot/diagnostic queries are bounded; Flutter serializes native mutations through a background isolate and suppresses UI-isolate snapshot polling while a native mutation owns the process runtime. FFI now exposes the runtime attachment-size capability directly.

No expensive build/platform/E2E checks were run manually for these source batches.
