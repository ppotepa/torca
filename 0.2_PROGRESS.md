## Completed evidence

- `02-00` through `02-13`: baseline, Bridge/runtime cleanup, daily-use UI, attachments, pairing recovery, diagnostics, verification, settings/localization and split CI gates.
- `02-14`: Read state is viewport/lifecycle aware and remote read receipts are an independent privacy preference.
- `02-15`: local encrypted state no longer waits for Tor during native construction; network startup runs in the background and Flutter serializes blocking FFI mutations outside the UI isolate.
- `02-16`: normal app snapshots use an overview actor request that does not load message bodies; SQLCipher owns bounded cursor paging, conversation summaries and literal in-conversation search; native exposes a dedicated history query ABI; Flutter uses a small timeline controller with latest/older/search behavior and memory/test fallback.
- `02-17`: host-level capture protection, Safety Number QR comparison, explicit identity-change security state and send blocking, shorter controlled plaintext export lifetime, and security documentation aligned with the actual non-ratcheting 0.2 transport.
- `02-18`: canonical Rust source roots replace `final_runtime`/versioned migration source names; Windows/Android runtime paths are version-neutral with one-time legacy migration; native composition is readable and stage-oriented; production attachment projections no longer require full message history; pairing uses overview snapshots; and the public C ABI exposes the v11 intent boundary instead of historical frontend-owned IDs/timestamps.

No expensive build/platform/E2E checks were run manually for these source batches.
