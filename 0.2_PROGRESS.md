# Torca implementation status

The unified runtime baseline is implemented and is being hardened through the ordered work in
[`docs/0.2/IMPLEMENTATION_ORDER.md`](docs/0.2/IMPLEMENTATION_ORDER.md). Rust workspace formatting,
clippy, tests and source-policy checks are expected build gates; Flutter analysis and tests are expected
client gates.

The remaining architecture work includes complete contract generation, lossless paging/error handling,
network I/O isolation, event-journal delivery, runtime-owned settings/diagnostics and snapshot slimming.
Release artifact validation remains separate from these source gates. Physical-device lifecycle and soak
validation run only when explicitly scheduled.
