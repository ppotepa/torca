### Batch 06 — Crypto adapters

**State:** **PARTIAL — PRODUCTION PROVIDER REQUIRED**

Delivered:

- `crates/infrastructure/torca-crypto`;
- redaction-safe private/public key, signature, nonce and ciphertext types;
- provider interface for generation, signing, verification, randomness and authenticated sealing;
- best-effort secret zeroing;
- deterministic test provider for simulations.

The deterministic provider is deliberately insecure and cannot be used in a distributable build. A reviewed production implementation remains a release blocker.

Documentation: [`docs/0.1/CRYPTO_CONTRACTS.md`](docs/0.1/CRYPTO_CONTRACTS.md).
