## 7. Local working-tree handoff

The local checkout contains the regenerated `Cargo.lock` and may already contain partial formatter changes. Pull the latest validation message update while preserving local changes:

```powershell
git status
git pull --rebase --autostash
```

Apply the formatter. This command mutates the Rust files and should produce no formatter diff on its second execution:

```powershell
./scripts/format.ps1 -SkipFlutter
./scripts/format.ps1 -SkipFlutter
```

Then inspect the result:

```powershell
git status --short
git diff --stat
git diff --check
```

The formatter-only Rust changes and `Cargo.lock` are expected. After that rerun:

```powershell
./scripts/validate.ps1 -SkipFlutter
```

Do not rerun `refresh-lock.ps1` unless Cargo explicitly reports a stale or invalid lockfile.
