## 5. Current work package

### Batch 03 — Protocol base

**State:** **QUEUED — NEXT**

Goal: introduce versioned wire envelope primitives, codec errors, strict size limits and compatibility tests without adding messaging-specific payloads.

Required deliverables:

- create `torca-wire` as a separate protocol crate;
- define protocol version and message-kind primitives;
- define a bounded wire header and payload envelope;
- establish maximum frame/header/payload limits;
- define decode/encode error taxonomy;
- keep serialization details independent from domain event envelopes;
- add deterministic compatibility and malformed-input tests;
- document compatibility and version negotiation rules;
- update this progress file.

### Next exact action

Create the `torca-wire` crate and implement only generic versioned framing primitives. Do not add message, pairing or relay payload schemas in Batch 03.
