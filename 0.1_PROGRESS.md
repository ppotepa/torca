## 4. Dependency lock state

New production dependencies were added for RustCrypto and bundled SQLCipher. The connector environment cannot run Cargo, so the checked-in `Cargo.lock` must be regenerated locally.

Run:

```powershell
./scripts/refresh-lock.ps1
./scripts/format.ps1
./scripts/validate.ps1 -SkipFlutter
```

Review and commit `Cargo.lock`. Until then, validation intentionally runs without `--locked`. Locked release validation must be restored after the generated graph passes locally.
