## Core source status

The original 20 dependency-ordered source batches are complete. The production path remains:

```text
Flutter -> EngineGateway -> Bridge -> torca-native -> NativeEngineRuntime
  -> ClientEngineActor -> RuntimeHost
     -> PairingDriver / OwnedTorDriver / TorcaCommunicationDriver
```

Rust/runtime owns Tor, pairing, peer sessions, durable delivery/retry, receipts, persistence, cryptography, relationship administration, attachment transfer/export and diagnostics data. Flutter owns presentation and platform UI integration only.

Current core gates remain source-complete but owner validation is open for Windows, Android, real Tor/two-client messaging, restart/reconnect, SQLCipher/protected secrets, attachments, notifications/deep links and release packaging. See [`docs/0.1/RELEASE_HANDOFF.md`](docs/0.1/RELEASE_HANDOFF.md) and [`docs/0.1/TEST_MATRIX.md`](docs/0.1/TEST_MATRIX.md).

Bridge contract before the PeerHealth slice remains **v9**. Pairing protocol remains **v2**. SQLCipher migration catalog remains **1–17**.

## Dependency/reproducibility status

`Cargo.lock` is reconciled. Flutter `pubspec.lock` still requires the first owner `flutter pub get`, inspection and accepted commit because this implementation environment has no Flutter/Dart SDK.
