### UI-14 evidence

The shared Flutter tree now owns desktop keyboard ergonomics without a separate desktop UI: `Ctrl+N` opens pairing, `Ctrl+,` opens Settings, `Ctrl+Shift+D` opens Diagnostics, and `Esc` dismisses the top application route. The Material app wraps routes in reading-order focus traversal, retains normal text scaling, and uses standard padded Material interaction targets. Existing right-click/long-press action models, tooltips and Material semantics remain shared across platforms.

Owner validation open: `flutter analyze`, `flutter test`, keyboard/focus traversal on Windows, text scaling/accessibility inspection, and Android regression checks.
