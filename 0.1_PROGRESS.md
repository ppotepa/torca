### Completed UI evidence

- UI-01: startup-loaded `themeMode`/`notificationsEnabled`; no preview preference; controlled temp export maintenance moved to Rust.
- UI-02: shared System/Light/Dark Material 3 themes and semantic colors.
- UI-03: focused Settings and shared application menu.
- UI-04: reusable canonical Tor/peer connection presentation.
- UI-05: runtime-owned PeerHealth probing reuses the authenticated peer link and includes RTT/freshness/failure/reconnect bookkeeping.
- UI-06: bridge contract bumped to v10; runtime network snapshots carry structured PeerHealth per contact; native JSON and Flutter FFI decode nested `PeerHealthDto`; schema and committed generated Dart remain identical; memory gateway preserves the health projection across contact presentation mutations.

UI-05/UI-06 owner validation requires Rust build/tests, `flutter analyze`, `flutter test`, contract/version check against the native library and real two-client PeerHealth sampling/reconnect validation.
