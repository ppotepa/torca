# Torca 0.1 alpha source baseline

Torca 0.1 defines the first clean modular architecture and complete source roadmap for a private Windows/Android 1:1 messenger over Tor.

Implemented source capabilities include local identity, explicit pairing, verified contacts, direct conversations, durable text-message state, receipts, bounded wire and peer protocols, ephemeral relay semantics, Tor lifecycle/SOCKS integration, generated Rust/Dart contracts, shared Flutter views, encrypted attachment storage contracts, diagnostics, release scripts and integration-test journeys.

This commit is not a validated binary release. See `docs/0.1/KNOWN_LIMITATIONS.md`, `docs/0.1/RELEASE_CHECKLIST.md` and root `0.1_PROGRESS.md` for open production integrations and owner-run validation status.
