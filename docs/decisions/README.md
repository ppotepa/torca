# Architecture Decision Records

ADRs record decisions that constrain future implementation.

## Status values

- proposed;
- accepted;
- superseded;
- rejected.

Accepted ADRs are not rewritten to reflect later preferences. A new ADR supersedes the old decision and links both records.
