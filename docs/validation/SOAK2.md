# Soak validation (archived name)

The active soak workflow is documented in [`SOAK1.md`](SOAK1.md). This file remains as a short link target for existing bookmarks; all runs use the Iroh provider and the isolated soak application profile.

Setup (build, install, permissions and pairing) is excluded from the measured battery window. Measurement records workload, Iroh profile, foreground/background state, CPU and Android battery artifacts. A cancelled run stops lab peers and writes a cancellation event.
